## Findings that need action before merge

   reads whatever `results/<condition>.json` files exist. `buildProvenance` compares

   controls and looks valid.

   live on `main` and cite files that exist only on `feat/primer-evals`. The branch
   deletes `pending-changes.md` and says the queue is "tracked as beans", but has no
   `.beans/`. Between df000ae and the merge, no tracker resolves on either side.
   Fix: commit the beans on the branch, or merge `main` into it.
