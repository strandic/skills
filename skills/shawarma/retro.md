# retro

On `retro`, run [retro-workflow.js](retro-workflow.js); the human decides; the record goes in the retros folder. Each lesson and open item since the last marker is adopted into the method or the house rules, or dropped. A lesson dropped as covered quotes the covering sentence and walks its own case through it; a recurrence re-adopts it. A pre-registered measure names the class that counts, an impact floor, the paths it covers, the committed artifact (one the measured process does not write) and the command that counts it, and its reading on the runs in hand before it is frozen; other counts, disclosed beside it, never decide; its consequence is honoured as written. This skill changes only at a retro, in words a stranger's repo could use: a new rule names the class of failure it prevents, never the case that prompted it. The retro reports tokens per load path (plan at the brief ending, plan at the questions ending, run, retro) before and after, by the skill repo's `scripts/size_paths` command; no load path grows unless the human rules it; the trap bank, not the count, decides each cut.
